Mouse
  • Left-drag rotate freely (flick to keep it turning)
  • Right-drag zoom · wheel zoom at the cursor
  • Middle-drag, Shift/Alt+drag pan
  • Middle-click the model: set the rotation centre
  • Double-click the background: reset the view
  • Click the model: place the text
  • Drag the text: move it · Ctrl+drag: rotate it
  • Wheel over the text: letter height
3Dconnexion SpaceMouse
Tilt/twist = rotate, push sideways = pan, pull up / push down = zoom. Left button = reset view, right button = next view.
